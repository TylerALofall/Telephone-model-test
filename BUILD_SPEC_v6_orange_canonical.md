# BUILD SPEC — SVG Tile Generator, one colour (write in C)

You are Opus 4.8, working alone, from this specification. It defines every
output, dimension, filename, and the exact letter bitmaps. Produce a C99
program, run it, verify, deliver. You author the program. Examples show the
required RESULT so you check your own work.

This colour: ORANGE, hex #FF8833.

## 1. GOAL
One C99 program, tilegen.c, that writes the complete orange tile set below.

## 2. CANVAS
Every SVG opens with exactly:
    <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 512 512" role="img">
512 by 512 for every file, so all tiles are interchangeable in a grid.

## 3. OUTPUT AND NAMING
All files in:  out/03_colors/orange/
Every filename:  03_colors_orange_[group]_[item].svg
  [group] = solid | ABC | abc | ball | balls | shapes
  [item]  = per section 5
Uppercase ABC sorts before lowercase abc. Examples:
    03_colors_orange_solid_screen.svg
    03_colors_orange_ABC_A.svg
    03_colors_orange_abc_a.svg
    03_colors_orange_ball_one.svg
    03_colors_orange_balls_seven.svg
    03_colors_orange_shapes_pentagon.svg

## 4. COLOUR RULE
Hex #FF8833 fills every coloured element. Non-colour backgrounds are white
#FFFFFF. Letters and shapes render in the colour on white. Solid screen is
entirely the colour.

## 5. THE TILES

### 5.1 SOLID SCREEN (solid, screen) — 1 file
    <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 512 512" role="img"><rect x="0" y="0" width="512" height="512" fill="#FF8833"/></svg>

### 5.2 LETTERS (ABC for A-Z, abc for a-z) — 52 files
CRITICAL: reproduce the EXACT bitmaps in section 10. Do not design your own
letterforms. The pattern must match the canonical grid cell for cell, even if a
letter looks rough. These grids are the shared source of truth: the same glyph
is used for the written letter, the sound link, and later freestyle drawing, so
recognition depends on every tile matching the canonical bitmap exactly.

Each glyph is 8 rows by 8 columns. A "#" is a lit cell, a "." is empty. Render:
  - 8x8 grid centered on the canvas.
  - Each cell 40 by 40. Glyph block 320. Origin (512-320)/2 = 96 for x and y.
  - Row r (0..7), column c (0..7): lit cell at
        x = 96 + c*40 , y = 96 + r*40 , width 40 , height 40 , fill #FF8833
  - Emit the white full-canvas background rect first, then one rect per lit
    cell in row-major order (row 0 left to right, then row 1, and so on).

Required result shape (uppercase A, first lit row shown):
    <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 512 512" role="img"><rect x="0" y="0" width="512" height="512" fill="#FFFFFF"/><rect x="216" y="96" width="40" height="40" fill="#FF8833"/> ...remaining lit cells of A... </svg>

### 5.3 BALL (ball, one) — 1 file
    <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 512 512" role="img"><rect x="0" y="0" width="512" height="512" fill="#FFFFFF"/><circle cx="256" cy="256" r="180" fill="#FF8833"/></svg>

### 5.4 SEVEN BALLS (balls, seven) — 1 file
White background, seven circles r=60: one at (256,256), six at radius 150 at
angles 0,60,120,180,240,300, x=256+150cos, y=256+150sin, rounded. Background,
center, then six in angle order:
    <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 512 512" role="img"><rect x="0" y="0" width="512" height="512" fill="#FFFFFF"/><circle cx="256" cy="256" r="60" fill="#FF8833"/><circle cx="406" cy="256" r="60" fill="#FF8833"/><circle cx="331" cy="386" r="60" fill="#FF8833"/><circle cx="181" cy="386" r="60" fill="#FF8833"/><circle cx="106" cy="256" r="60" fill="#FF8833"/><circle cx="181" cy="126" r="60" fill="#FF8833"/><circle cx="331" cy="126" r="60" fill="#FF8833"/></svg>

### 5.5 SHAPES (shapes) — 4 files: triangle, square, pentagon, hexagon
White background, one shape centered at (256,256), colour fill, each on a
radius-180 bounding circle.
  - triangle: 3 vertices, first at -90 (up), then +120, +240.
  - square: rect x=76 y=76 width=360 height=360.
  - pentagon: 5 vertices, first -90, step 72.
  - hexagon: 6 vertices, first -90, step 60.
Polygons use <polygon points="..."> rounded to whole numbers. Background first.
    <svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 512 512" role="img"><rect x="0" y="0" width="512" height="512" fill="#FFFFFF"/><rect x="76" y="76" width="360" height="360" fill="#FF8833"/></svg>

1 solid + 26 ABC + 26 abc + 1 ball + 1 balls + 4 shapes = 59.
Program prints the count and errors if it is not 59.

    BITMAP MATCH: uppercase R and lowercase a match section 10 cell-for-cell? yes/no
    FILES: <name> <bytes>, one line each
    BUNDLE: <zip path> <bytes>
    ASSUMPTIONS MADE: <or "none">
    BLOCKED ON: <or "nothing">
